# Super Meat Boy — 106% Completion Tracker

Unofficial HTML/CSS/JavaScript tracker for Super Meat Boy.

## Included
- 106% completion ceiling, including six glitch levels
- 250 standard level checklist
- Bandage and A+ tracking
- Dark-world, warp-zone and boss tracking
- 48 Steam achievements with artwork
- Platform filters for Steam/PC, PlayStation and Xbox 360
- Earned / not-earned filters
- Local browser persistence
- Responsive CSS and GitHub Pages support
